Problem Statement

People often don't know which nearby supermarket stocks a specific food product before leaving home — leading to wasted journeys and failed shopping trips.

Interaction Design + UI Sketch

Enter Product Name

User states their intent. The system listens, autocompletes, and confirms what to look for before proceeding.

Interaction Design Flow
User action: tap search field
User taps the search field→ Keyboard appears · field activates (focused state · blue border)
User types a product name→ Autocomplete suggestions appear after 2+ characters (debounce 300 ms)
User selects a suggestion or finishes typing→ Field fills with selected text · suggestion list closes · border turns green
User taps "Next →"→ Transition to Step 02 (Set Location)
State changes
idle→focusedon tap
focused→typing + suggestions
typing→confirmedon select
submit empty→error: "Enter a product"
💡 Micro-interaction: field border animates gray → blue on focus, then green on valid input. Empty submit shakes the field (CSS keyframe).

02
Interaction Design + UI Sketch

Set Location

User grants GPS access or enters an address manually. A radius slider lets them control how wide to cast the search net.

Interaction Design Flow
Screen presents two options→ "Use my location" (GPS) or "Enter address manually"
User taps "Use my location"→ OS permission dialog appears (system-level prompt)
Permission granted→ GPS pin drops on mini-map · dashed radius ring appears
User drags radius slider (1–10 km)→ Radius ring expands / contracts live on map · haptic feedback on iOS
User taps "Search this area"→ Proceed to Step 03
State changes
no location→permission pending
permission granted→location confirmed
permission denied→manual input shown
💡 Fallback: if GPS unavailable, text field for city/address appears. Default radius: 3 km. Slider snaps to whole-km increments.

03
Interaction Design + UI Sketch

Search

The system queries nearby stores in real time. The user sees live status — not a blank spinner — so they know the system is working.

Interaction Design Flow
User taps "Find Product" (or system auto-triggers)→ Loading screen appears · progress bar starts at 0%
System scans nearby stores one by one→ Live status line cycles: "Checking Magnum… Checking Small…"
Each store completes check→ ✓ or ✕ appears next to store name · progress bar advances
Search finishes (or 5 s timeout)→ Toast: "Found in X stores!" · auto-navigates to Results
State changes
idle→searching (0–100%)
first result found→partial results ready
no stores found→empty state — widen radius?
💡 Progress bar animates smoothly even when results arrive fast — prevents jarring instant jumps. Cancel button always visible.

04
Interaction Design + UI Sketch

Get Results

A ranked list of stores that carry the product — sorted by distance by default, with price and stock shown at a glance.

Interaction Design Flow
Results list animates in (cards stagger 80 ms apart)→ Best match card highlighted at top with "Best" badge
User taps a filter chip (Distance / Price / Rating)→ List reorders in place with smooth slide animation
User taps a store card→ Card expands to show: aisle number, exact price, stock level
User taps "Get Directions"→ Transition to Step 05 (navigation)
State changes
loading→results rendered
card collapsed→card expandedon tap
no results→empty state + suggestions
💡 Out-of-stock stores shown last in muted style with ❌. "Best" badge uses accent orange. Filter change reorders without full reload.

05
Interaction Design + UI Sketch

Get Directions

Turn-by-turn navigation guides the user to the store entrance. A geofence triggers an arrival banner showing the product's exact aisle.

Interaction Design Flow
User taps "Get Directions" on chosen store→ Full-screen map opens · route drawn as dashed line
User selects transport mode (walk / drive / transit)→ ETA and route recalculate instantly
Turn-by-turn steps listed below map→ Tapping a step highlights that segment on the map
User enters 50 m geofence around store→ Arrival banner fires: "You're here! Aisle 7"
User marks complete→ 🎉 Confetti · option to rate store or save product to list
State changes
route loading→route ready
en route→navigating
geofence triggered→arrived 🎉
💡 Geofence: 50 m radius. Arrival banner stays until dismissed. "Rate store" prompt appears 60 s after arrival. Share route option available.
